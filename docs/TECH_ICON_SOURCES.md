# Technology icon sources

SVGs are stored locally so project stacks do not depend on third-party image requests. Simple Icons SVGs use their catalog brand colors. The CC0 license is in [SIMPLE-ICONS-LICENSE.md](../public/tech-icons/SIMPLE-ICONS-LICENSE.md). Brand names and marks belong to their owners and identify technologies used by these projects.
